# Состояние проекта для ИИ (AI State Checkpoint)

<p style="margin: 0.5em 0px;">Этот файл предназначен для синхронизации контекста между различными сессиями ИИ. Он должен обновляться после каждого значимого изменения в проекте.</p>

## 🎯 Глобальная цель проекта (Project Goal)

<p style="margin: 0.5em 0px;">Создание мощного клона Obsidian с поддержкой Markdown, интерактивного предпросмотра (Preview), режима разделенного экрана (Split Screen) и продвинутого визуального редактора (Design Mode) на базе React, TypeScript и Electron.</p>

## 🏗 Архитектура и стек (Architecture & Stack)

*   **Стек**: React, TypeScript, Electron (через глобальный интерфейс `window.electronAPI`), сборка через Vite.
*   **Главные компоненты**:
    *   `App.tsx`: Управление состоянием (выбранный файл, дерево файлов), управление режимами (`viewMode`: `edit`, `preview`, `split`) и флагом `designMode`.
    *   `Editor.tsx`: Текстовый редактор Markdown (на основе CodeMirror). Поддерживает синхронизацию позиции курсора (`activeSourcePos`).
    *   `Preview.tsx`: Основной движок рендеринга и визуального редактирования. Использует `ReactMarkdown` для отрисовки, `contentEditable` для Design Mode и `turndownService` для обратной конвертации HTML в Markdown. Обрабатывает Drag & Drop.
    *   **Сетки (Grid)**: Кастомная реализация сеток на основе flex/grid (`.dashboard-grid`, `.grid-cell`, `.flex-row`, `.flex-col`).

## ✅ Что было реализовано недавно (Recently Implemented)

*   **Синхронизация и выделение**: Выделение элементов (рамки и `selected-block`) отключено в чистом режиме чтения (`viewMode === 'preview'`). В режиме `split` клик по превью синхронизирует курсор редактора (`hasEditor` prop). В режиме `designMode` клик выделяет элемент для редактирования.
*   **Вложенные сетки**: Исправлены проблемы с CSS отступами (margin-bottom) у вложенных сеток.
*   **Пустые ячейки**: Исправлено визуальное выделение пустых ячеек в Design Mode.
*   **Очистка HTML**: Функция `cleanHTML` теперь корректно вычищает автоматически генерируемые браузером теги `<p:empty>` и `<br>`, предотвращая поломку разметки.
*   **Рефакторинг**: Избавились от дублирования кода, создав `CodeBlockHeader` и вынеся повторяющиеся inline-стили в константы. Вынесли гигантскую логику из `Preview.tsx` в отдельные хуки `useDragAndDrop.ts` и `useInteractions.ts`, сократив код на ~800 строк.
*   **Файловый менеджер**: Теперь в дереве файлов (FileExplorer) и поиске отображаются не только `.md` файлы, но и все поддерживаемые фотографии и видео. Фильтрация переведена на механизм белого списка (ALLOWED\_EXTS).

## 📝 Правила для ИИ (AI Guidelines)

1.  **Обновляй этот файл**: После каждого успешно завершенного таска актуализируй секции "Что было реализовано" и "Текущий статус".
2.  **Веди CHANGELOG**: Пользователь требует, чтобы все изменения для него записывались в файл `CHANGELOG.md`. Не забывай это делать!
3.  **CSS-осторожность**: При работе со стилями `Preview.css` учитывай высокую специфичность селекторов (например, `.design-mode-container`).
4.  **Конвертация**: Любое добавление новых HTML-сущностей должно сопровождаться проверкой, как это обрабатывается в `turndownService` внутри `Preview.tsx`.
