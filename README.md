# bytonite LMS


> Bytonite LMS — инновационная образовательная платформа для учителей, учебных центров и образовательных учреждений. Она объединяет конструктор интерактивных курсов, тестирование, аналитику прогресса и ИИ-помощника, помогая персонализировать обучение и повышать его эффективность.

## ✨ Возможности

| Функция | Описание |
|---|---|
| 📝 **Markdown-редактор** | CodeMirror 6 с подсветкой синтаксиса |
| 🔍 **Live Preview** | Двух-панельный режим с синхронизацией курсора |
| 🎨 **Design Mode** | Визуальный WYSIWYG-редактор с Drag & Drop блоков |
| 📊 **Mermaid-диаграммы** | Рендер, зум, перетаскивание в ячейки |
| 🗂 **Сетки и лейауты** | Гибкие grid-ячейки, flex-строки, дашборды |
| 🖼 **Медиа** | Вставка изображений и видео (перетаскивание, буфер обмена) |
| 📦 **Шаблоны** | Готовые блоки (коллауты, сетки, таблицы, код) |
| 💾 **Автосохранение** | Мгновенное сохранение при каждом изменении |
| ↩️ **Undo / Redo** | `Ctrl+Z` / `Ctrl+Y` в режиме дизайна |

## 🛠 Технологии

| | |
|---|---|
| **React 18** + TypeScript | UI и компонентная архитектура |
| **CodeMirror 6** | Редактор кода с подсветкой синтаксиса |
| **ReactMarkdown** + rehype-raw | Рендер Markdown с поддержкой HTML |
| **Mermaid** | Рендер диаграмм (flowchart, sequence, gantt и др.) |
| **TurndownService** | Конвертация HTML → Markdown при автосохранении |
| **Vite** | Сборка фронтенда |
| **Electron** | Десктоп-приложение с доступом к файловой системе |

## 📋 История версий

### v1.22.2 — Drag & Drop диаграмм в ячейки
- Mermaid-диаграммы теперь можно перетаскивать в ячейки сетки и другие блоки
- Drag handle в левом верхнем углу диаграммы
- Smart selection: при перетаскивании захватывается весь `<pre>`-блок

### v1.22.1 — Адаптивный зум диаграмм
- Зум через `SVG width/height` вместо `transform: scale()` — диаграмма теперь физически расширяет блок и толкает соседние элементы вниз
- Формула: `effectiveScale = min(fitScale, userScale)` — при уменьшении контейнера диаграмма уменьшается, при увеличении — растёт только до выбранного размера
- `ResizeObserver` на каждом враппере — автопересчёт при изменении размера панели

### v1.22.0 — Система зума Mermaid-диаграмм
- **Design Mode**: плавающий тулбар при наведении (+/− кнопки, Ctrl+Wheel)
- **Reading Mode**: диаграмма отображается в сохранённом масштабе, взаимодействие полностью заблокировано
- Зум сохраняется в markdown как `%% zoom: {"scale":1.5,"x":0,"y":0}`
- Исправлен критический баг: тулбар зума был мёртвым кодом из-за раннего `return` в `Preview.tsx`

### v1.21.0 — Undo/Redo, стилизованные скроллбары
- Кастомные стилизованные скроллбары (светлая/тёмная темы)
- История изменений: Undo/Redo (`Ctrl+Z` / `Ctrl+Y`), удаление блоков (`Delete`)
- Исправлен баг «Grid Blowout» при сплит-экране
- Улучшен интерфейс поиска: сниппеты текста для наглядности совпадений

### v1.20.0 — Панель свойств, прозрачность, шаблоны
- Поля размеров в `PropertiesPanel`: показывают актуальные computed-стили, сохранение по `Enter`/blur, автодобавление `px`
- Кнопка прозрачного цвета для фона, текста и границ
- Шаблон «Блок кода» в панели шаблонов

### v1.17–1.19 — Live Preview синхронизация
- Плагин `remarkInjectSourcePos` — точные координаты для всех HTML-блоков
- `useLayoutEffect` для подсветки активного элемента без мигания
- Синхронизация курсора кода ↔ превью для любых вложенных структур

### v1.10–1.16 — Design Mode: основа
- Мультивыделение блоков (`Ctrl+Click`), `PropertiesPanel`
- Drag & Drop с визуальным индикатором и контейнерами-целями
- Зелёный Drag Handle для перетаскивания блоков
- Ресайзер боковой панели
- Автосохранение с таймером (debounce 1.5 сек)

### v1.0–1.9 — Начало
- Базовый Markdown-редактор с Electron
- Древо файлов, поиск по содержимому
- Первый Design Mode с Drag & Drop и выделением блоков

## 📂 Структура проекта

```
src/
├── components/
│   ├── Preview.tsx              # Основной рендер (Reading + Design Mode)
│   ├── MermaidReactComponent.tsx # Компонент Mermaid-диаграммы
│   ├── Preview.css              # Стили превью
│   ├── TextToolbar.tsx          # Тулбар форматирования текста
│   ├── PropertiesPanel.tsx      # Правая панель свойств
│   └── markdown/                # Компоненты ReactMarkdown
├── hooks/
│   ├── useMermaidRender.ts      # Рендер и responsive zoom диаграмм
│   ├── useDragAndDrop.ts        # Drag & Drop блоков
│   ├── useAutoSave.ts           # Автосохранение + Undo/Redo
│   └── useResize.ts             # Ресайз элементов мышью
└── utils/
    ├── htmlToMarkdown.ts        # HTML → Markdown (Turndown + правила)
    ├── markdownUtils.ts         # rehype-плагины
    └── uriTransform.ts          # Трансформация URI изображений
```
