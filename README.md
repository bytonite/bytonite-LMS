## ⚡ Запуск

```bash
npm install
npm run dev:server   # только веб-версия (порт 5173)
npm run dev          # веб + Electron
```

## 🛠 Технологии

- **React 18** + TypeScript
- **CodeMirror 6** — редактор кода
- **ReactMarkdown** + rehype-raw — рендер Markdown
- **Vite** — сборка
- **Electron** — десктоп-версия
